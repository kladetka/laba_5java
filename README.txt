Лабораторна робота №5 — Java, варіант 10

Файли:
- Main.java — усі 5 завдань.
- input_l1.txt — список L1 для завдання 2.
- input_l2.txt — список L2 для завдання 2.
- input_words.txt — слова для завдання 3.

Запуск:
1. Відкрийте папку в IntelliJ IDEA.
2. Переконайтеся, що встановлено JDK 11 або новіший (використовується Files.readString).
3. Запустіть Main.java.
4. Виберіть завдання цифрами 1–5 у меню.

Завдання 2:
Програма читає слова з input_l1.txt і input_l2.txt, видаляє з L1 кожне слово, яке є в L2,
і записує результат в output_l1.txt по чотири слова в рядку.

Завдання 3:
Програма читає слова з input_words.txt, групує унікальні слова за довжиною
і показує ключі (довжини) за зростанням.

Дані для завдань 1, 4 і 5 задані в коді як тестова колекція HotelRoom.
